# Task 1 — To-Do List

A simple command-line To-Do List application built using Python. The program allows users to add, view, and delete tasks through a menu-driven interface.

## Features

- Add new tasks
- View all available tasks
- Delete a task using its task number
- Menu-driven interface
- Input validation
- Prevents empty tasks
- Handles invalid user input

## Concepts Used

- Functions
- Lists
- `while` loop
- `for` loop
- `if-elif-else`
- `try-except`
- `append()`
- `pop()`
- `enumerate()`
- User input

## How It Works

1. The program displays a menu.
2. The user selects an option from 1 to 4.
3. The user can:
   - Add a task
   - View existing tasks
   - Delete a task
   - Exit the program
4. The program continues running until the user selects **Exit**.

## How to Run

Make sure Python 3 is installed on your computer.

Run the following command:

```bash
python task1_todo_list.py
```
